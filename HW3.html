01 / DEFINE THE EXPERIMENT

A system is a step.
An attacker is a path.

Every attacker encounters the same number of systems. All increments are independent, both across steps and across attackers.

MODEL A / SUCCESS COUNTS

Bernoulli increments

Xᵢ ∈ {0, 1}
P(Xᵢ = 1) = p
μ = p   σ² = p(1 − p)

A successful penetration adds 1. A failed attempt adds 0. The total Sₙ counts successful attacker–system attempts, so it never decreases. Each attacker makes one attempt per system.

Sₙ ~ Binomial(n, p)
MODEL B / SIGNED SCORES

Rademacher increments

Xᵢ ∈ {−1, +1}
P(Xᵢ = +1) = P(Xᵢ = −1) = ½
μ = 0   σ² = 1

+1 means a gain; −1 means an equally weighted setback. This is a symmetric random walk. Its score can be negative: it is a net score, rather than a count of compromised systems.

Sₙ = 2Bₙ − n,   Bₙ ~ Binomial(n, ½)
Notation. For attacker j, Sj,k = ∑i=1k Xj,i, with Sj,0 = 0. The homework's Sₙ is one attacker's score at the final system. The m attackers provide independent replications of that stochastic process.

03 / THE LAW OF LARGE NUMBERS

Averages settle.
Totals need not.

Convergence in probability concerns the chance of a deviation. It does not require every sample trajectory to improve at every step.

The LLN statement

For every fixed ε > 0:
P(|Sₙ/n − μ| > ε) → 0 as n → ∞.

Sₙ/n → μ in probability.

The mean is p for Bernoulli increments and 0 for Rademacher increments. Increasing n concentrates each attacker's average around that mean. A finite experiment illustrates this result; it does not prove a limiting theorem.

A direct variance argument

P(|Sₙ/n − μ| > ε) ≤ σ²/(nε²)

Chebyshev's inequality gives a bound tending to zero. The displayed bound is capped at 1, since probabilities cannot exceed 1. It can be much larger than the actual probability.

04 / VARIANCE UNDER RESCALING

One sum.
Three different scales.

Independence gives Var(Sₙ) = nσ². Multiplying a random variable by a constant c multiplies its variance by c².

QuantityExpectationVarianceAs n grows
Sₙnμnσ²For σ² > 0, the variance grows linearly. The typical centered fluctuation is of order √n.
Sₙ / nμσ² / nThe variance tends to zero, so the average concentrates around μ.
Sₙ / √nμ√nσ²The variance stays constant. A nonzero mean still moves with √n.
Spread versus location. Constant variance does not guarantee convergence to a fixed distribution. For Bernoulli p > 0, Sₙ/√n has mean p√n and tends to +∞ in probability. Centering is essential. When p = 0 or 1, the Bernoulli process is deterministic and all variances are zero.
05 / THE CENTRAL LIMIT THEOREM

Fluctuations find
a familiar shape.

The CLT describes the distribution across independent trajectories at a large fixed n. One trajectory need not converge to a fixed value.

Center, then standardize.

Zₙ = (Sₙ − nμ) / (σ√n)
Zₙ ⇒ N(0, 1), provided σ² > 0.

Rademacher: μ = 0 and σ = 1, so Zₙ = Sₙ/√n exactly. Its variance is already 1 for every n; the shape approaches normal as n grows.

Bernoulli: Zₙ = (Sₙ − np)/√[np(1 − p)]. Dividing by √n alone leaves mean p√n and variance p(1 − p); it does not give a standard normal limit.

At finite n these scores are discrete. Rademacher totals also have the same parity as n. Normal convergence is in distribution, not pointwise equality of probability masses.

06 / BACK TO SYSTEMS & ATTACKERS

What does the
score actually measure?

The simulation separates a larger system population from a larger population of independent attackers.

Increase n: longer paths.

Each attacker attempts more systems. Bernoulli totals have mean np; signed Rademacher totals keep mean 0 but standard deviation √n. In both cases the per-system average becomes more stable. For Bernoulli, the probability that one attacker succeeds at least once is 1 − (1 − p)ⁿ.

Increase m: more replications.

The distribution of a single attacker's Sₙ stays the same. More attackers make the empirical histogram and estimated means more stable. Monte Carlo standard errors typically fall like 1/√m. A smoother histogram at fixed n does not mean the CLT approximation improved.

Aggregate: add the paths.

For Aₙ = ∑j=1mSj,n, independence gives E[Aₙ] = mnμ and Var(Aₙ) = mnσ². Thus Var(Aₙ/(mn)) = σ²/(mn). There are mn attempted encounters; the summed score includes all of them.

Aggregate score in this run

Run the experiment to inspect the aggregate score.

Successful attempts ≠ distinct systems.

Several attackers may succeed against the same system. In the Bernoulli model, Aₙ counts successful attempts and can exceed n.

P(a given system is penetrated)
= 1 − (1 − p)ᵐ
E[distinct penetrated systems]
= n[1 − (1 − p)ᵐ]

This follows from the independent attacker assumption. The expected distinct-system count saturates at n as m grows; the expected attempt count mnp keeps increasing.

Interpret the model within its assumptions.

Systems have identical success probability; attackers do not learn, cooperate, exhaust resources, or change the defenses. No real systems are contacted. Shared vulnerabilities and coordinated attackers can create dependencies; then Var(Sₙ) includes covariance terms and these formulas may no longer apply. The Rademacher model studies symmetry and signed fluctuations, rather than a realistic compromise count.

07 / REPRODUCE & EXPLAIN

From experiment
to a homework argument.

Use the same settings and seed to reproduce a run. Export the checkpoint data to calculate your own summaries.

A useful experimental sequence

  1. Start with Rademacher, n = 1000 and m = 2000. Inspect increasing checkpoints. Compare the three empirical variances with their theoretical values.
  2. Increase n to 10000. Check concentration of Sₖ/k near 0 and the standardized histogram near N(0, 1).
  3. Switch to Bernoulli with p = 0.3. Observe the average near 0.3 and the uncentered Sₖ/√k shifting right.
  4. Compare m = 100 with m = 5000 at fixed n. Explain smoother empirical distributions without a change in the underlying single-attacker law.
  5. Try p = 0.01 at small n, then large n. Skewness persists when expected successes are small. Finally try p = 0 or 1.

Simulation method

A seeded Mulberry32 pseudorandom generator produces U in [0, 1). Each draw becomes 1{U < p} for Bernoulli or +1 if U < ½ and −1 otherwise for Rademacher. This is Monte Carlo sampling, not cryptographic randomness.

Paths are sampled at up to 300 plotting points; the first 24 are drawn. All mn increments are generated, and all m exact endpoints are kept at every reported checkpoint. No normal approximation is used to generate scores.

Histogram bars give observed fractions per bin. Gold marks give Gaussian probabilities integrated over those exact bins. Axes adapt to the data; numerical variance is the reliable comparison across scales.

A seed reproduces the entire run with the same parameters. Changing n or m starts a new experiment; checkpoints within a run are the controlled prefix comparison.

Show the core algorithm and exported data fields
for each attacker j = 1, …, m:
    score = 0
    for each system i = 1, …, n:
        u = nextSeededUniform()
        x = (u < p ? 1 : 0)                 // Bernoulli
        // or: x = (u < 0.5 ? +1 : -1)      // Rademacher
        score += x
        if i is a checkpoint:
            save score, score / i, score / sqrt(i)

At each checkpoint, summarize across all m attackers.
Empirical variance = mean((value - empiricalMean)^2).

CSV fields: model, p, seed, configured_n, m, epsilon, attacker, k, total, average, normalized_total, standardized_z. For Rademacher p is 0.5. For deterministic Bernoulli runs standardized_z is empty.
