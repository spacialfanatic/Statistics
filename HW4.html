EXERCISE 01 / DERIVE & IMPLEMENT

From the mean
to the sum of squares.

The same idea behind Knuth’s running mean extends to the second central moment: update the previous state using only the new observation.

Notation. For observations x₁, …, xk, let x̄k be their mean and SSk = ∑i=1k(xi − x̄k)². SS is an unnormalized central sum of squares, also called M₂; it is neither ∑xᵢ² nor a variance until divided by a denominator.
01

Start with Knuth’s mean recurrence.

Write the previous sum as (k − 1)x̄k−1, add the incoming observation, and divide by k. The difference δk measures how far the new score lies from the previous mean.

δk = xk − x̄k−1
x̄k = [(k − 1)x̄k−1 + xk]/k = x̄k−1 + δk/k

At k = 1, initialize x̄₀ = 0 and SS₀ = 0; the update gives x̄₁ = x₁ and SS₁ = 0.

02

Recenter the previous observations.

For k ≥ 2, the new mean shifts the center by δk/k. Expand the squares for the first k − 1 observations. Their residuals about the old mean sum to zero, so the cross term disappears.

SSk = ∑i=1k−1[(xi − x̄k−1) − δk/k]² + (xk − x̄k)²
∑i=1k−1(xi − x̄k−1) = 0
SSk = SSk−1 + (k − 1)δk²/k² + (xk − x̄k)²
03

Combine the two correction terms.

The new residual is xk − x̄k = (k − 1)δk/k. Substituting it yields Welford’s recurrence.

SSk = SSk−1 + [(k − 1) + (k − 1)²]δk²/k²
SSk = SSk−1 + [(k − 1)/k]δk²
SSk = SSk−1 + δk(xk − x̄k)
DESCRIPTIVE VARIANCE / DIVIDE BY k

The second empirical central moment.

vk = SSk/k
vk = [(k − 1)/k]vk−1
+ [(k − 1)/k²]δk²

Use v₁ = 0; the recurrence applies for k ≥ 2. This describes the observed scores, but as an estimator of an unknown population variance it is biased downward: E[vk] = [(k − 1)/k]σ².

UNBIASED SAMPLE VARIANCE / DIVIDE BY k − 1

Bessel’s correction.

sk² = SSk/(k − 1)
sk² = [(k − 2)/(k − 1)]sk−1²
+ δk²/k

The direct recurrence applies for k ≥ 3, with s₂² = (x₂ − x₁)²/2. Computing from SS works for every k ≥ 2. Sample variance is undefined for k < 2. Throughout Exercise 2, “sampling variance” means this unbiased estimator.

The core update, in three lines.

O(1) storage · O(n) time
JAVASCRIPT / INSIDE THE OBSERVATION LOOP
const delta = x - mean;
mean += delta / ++n;
M2 += delta * (x - mean);

Initialize n = 0, mean = 0, M2 = 0. The second line increments the observation count before division. The last line must use the updated mean. Return M2 / (n − 1) for the unbiased variance when n ≥ 2.

Complete reusable function
function welford(values) {
  let n = 0, mean = 0, M2 = 0;
  for (const x of values) {
    const delta = x - mean;
    mean += delta / ++n;
    M2 += delta * (x - mean);
  }
  return {
    count: n,
    mean: n ? mean : null,
    SS: M2,
    variance: n > 1 ? M2 / (n - 1) : null
  };
}
Why this update is useful. It needs no stored history and avoids subtracting the potentially very large quantities ∑xᵢ² and n·x̄². This usually gives better floating-point behavior, although it does not eliminate rounding error.

Calculate the population moments.

Two levels of averaging. Each hacker j produces x̄j,n and sj,n² from n scores. Across m hackers, compare An = (1/m)∑j=1mx̄j,n with μ and Bn = (1/m)∑j=1msj,n² with σ². The spread of the m individual estimates is a different quantity from either average.

Here σ⁴ means (σ²)² = 100. The variance formula for s² is valid for iid observations with a finite fourth moment; no normal population assumption is used.

Why divide by n − 1?

Use SSn = ∑(Xᵢ − μ)² − n(x̄n − μ)². Taking expectations gives nσ² − n(σ²/n) = (n − 1)σ². Therefore E[SSn/(n − 1)] = σ².

Estimating the unknown center from the sample consumes one degree of freedom: the n deviations from x̄ sum to zero.

Why does the sample variance stabilize?

For this distribution, Var(sn²) = 78/n + 200/[n(n − 1)], which tends to zero. Together with E[sn²] = 10, this proves mean-square consistency and hence convergence in probability.

As n grows, SD(x̄n) ≈ √10/√n and SD(sn²) ≈ √78/√n. Multiplying n by four approximately halves both spreads for large n.

How the simulation is organized
  1. For each hacker j = 1, …, m, generate nmax pseudorandom scores as floor(11U), with U in [0, 1). A seeded generator makes the run reproducible.
  2. Apply the three-line Welford update to every score. At n = 2, 5, 10, 30, 100, 300, 1000, 3000 and 10000, retain the mean and SS/(n − 1), up to the chosen maximum.
  3. At each checkpoint, average the m means and the m unbiased variances. Measure each estimator’s empirical SD across the hackers with denominator m − 1.
  4. Compare with the exact expectations and SDs in the table. Different rows reuse prefixes of the same trajectories; hackers remain independent in the statistical model.
  5. Retain at most 16 thinned trajectories for drawing. The numerical summaries use all m hackers and all observations, regardless of the plotting resolution.

The seeded pseudorandom generator approximates iid sampling; the theory assumes ideal independent draws. This is a statistical simulation rather than a model of adaptive attackers or heterogeneous real defenses.

INTERPRETATION / ANSWERS TO EXERCISE 02

Unbiased at every n.
More precise as n grows.

A single experiment fluctuates. The theoretical expectations explain the targets; the sampling variances explain the size of the fluctuations.

Compare the two averages.

An should be near 5 and Bn near 10. Both are unbiased for every n ≥ 2, so increasing n does not correct a bias in these estimators. Their realized errors need not decrease monotonically in a particular run.

Increase the systems n.

Every hacker has more observations. Both the sample means and sample variances become less variable across hackers; their histograms concentrate around 5 and 10. The sample variance need not have a symmetric or normal distribution at small n.

Increase the hackers m.

At fixed n, the distribution of an individual estimate stays the same. More replications reveal that distribution more clearly and reduce the standard errors of An and Bn by a factor proportional to 1/√m.

Why this matters for inference.

Usually μ and σ² are unknown: we only observe a sample. Unbiasedness tells us the estimators hit the correct targets on average; consistency tells us more data make them concentrate around those targets.

The estimated standard error s/√n quantifies uncertainty in a sample mean. For sufficiently large n, the CLT motivates the approximate interval x̄ ± 1.96s/√n for μ. Its finite-sample coverage is approximate here because the scores are discrete uniform.

What the simulation can establish.

Here the population moments are known, so the experiment checks the behavior predicted by the formulas. Agreement is empirical evidence, while the expectation and variance identities provide the mathematical justification.

Averaging sample variances estimates the population score variance. It does not estimate the variance of the sample mean: that is σ²/n. Confusing these quantities would overstate uncertainty by a factor n in variance.

The practical result.

Welford’s update provides both estimates in a single pass with constant storage. Bessel’s correction makes the sample variance unbiased. Larger n improves each hacker’s estimates; larger m improves the precision with which the experiment describes their sampling distributions.
