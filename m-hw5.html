EXERCISE 01 / RIEMANN & LEBESGUE

Integrate across x.
Then integrate across values.

01 / Domain partitions

Split [a,b] into N equal intervals of width h. The midpoint rule uses one function value per interval, so it is a tagged Riemann sum.

RN = h ∑i=0N−1 f(a + (i + ½)h)
h = (b − a)/N

For twice continuously differentiable functions, its error is O(N−2). Jumps, corners and an unbounded endpoint require separate analysis; convergence alone does not certify Riemann integrability.

02 / Measurable value levels

For nonnegative f, let H(y) = μ{x ∈ [a,b] : f(x) > y}. Partition [0,M] with δ = M/N. Integrating the simple function δ∑1{f>(j+½)δ} gives a range-based approximation.

LN = δ ∑j=0N−1 H((j + ½)δ)
∫ min(f,M) dx = ∫0M H(y) dy

Domain preimages supply the measures. They are obtained analytically here, except for sinc, whose level boundary uses 48 bisection steps. This is a Lebesgue-inspired numerical scheme, not a universal algorithm for measuring arbitrary sets.

Where both definitions agree

A bounded function on a compact interval is Riemann-integrable exactly when its discontinuities form a set of measure zero. In that case it is Lebesgue-integrable, and both integrals agree.

The continuous examples, the corner at ½ and the two finite step functions meet this condition. Midpoints can be unusually accurate when a jump or corner aligns with the grid. Refinement need not reduce every error monotonically.

The range scheme has an O(M/N) worst-case bound on a bounded domain, even though particular examples converge faster or are exact. Neither viewpoint guarantees a faster numerical algorithm.

Unbounded is a different case

For 1/√x, the proper Riemann integral on [0,1] does not exist because the function is unbounded. Its improper Riemann integral and Lebesgue integral both equal 2.

∫ min(f,M) dx = 2 − 1/M
∫ (f − M)+ dx = 1/M

The experiment sets M = √N. It reports the clipped range estimate without adding the known tail, so its error includes truncation. Both δ = 1/√N and the omitted tail tend to zero. A substitution x = t² removes the singularity and gives the constant integrand 2.

Dirichlet / sampling can mislead

For 1ℚ, every interval contains rational and irrational numbers: lower Darboux sums are 0 and upper sums are 1. There is no Riemann integral. The Lebesgue integral is 0 because ℚ has measure zero.

The table deliberately uses rational tags (2i+1)/(2N), giving 1 for every N. Irrational tags give 0 instead. This is a symbolic construction: JavaScript never attempts to classify a floating-point number as a mathematical rational or irrational.

Thomae / dense spikes, zero area

Thomae’s function is 1/q at a reduced fraction p/q and 0 at irrational x. It is continuous at irrational points and discontinuous at rational points. It is therefore Riemann-integrable, with integral 0, matching its Lebesgue integral.

At the rational midpoint (2i+1)/(2N), the exact value is gcd(2i+1,2N)/(2N). These values produce the table. For any ε > 0, only finitely many reduced fractions have 1/q ≥ ε; small neighborhoods of them make the upper sums arbitrarily small.

Cost and interpretation. Midpoints need N function evaluations and O(1) working memory. Range midpoint sums need N preimage measures; the displayed lower/upper checks add 2N calls. Closed-form measures make most cases O(N), while sinc requires about 48N sine evaluations for its midpoint estimate alone. If preimages must instead be estimated from a domain grid, that introduces a second numerical error and may erase any speed advantage. All examples are nonnegative; signed functions can be treated through f = f⁺ − f⁻ when ∫|f| is finite.
EXERCISE 02 / THE STANDARD NORMAL CDF

A probability with
no elementary antiderivative.

φ(x) = e−x²/2/√(2π)   ·   Φ(z) = ∫−∞z φ(x) dx
Φ(z) = ½ + ∫0z φ(x) dx = ½[1 + erf(z/√2)]

Quadrature / a finite interval

Symmetry removes the infinite endpoint exactly. With h = z/N, the trapezoidal rule weights endpoints by ½. Simpson uses weights 1,4,2,…,4,1 and requires even N.

Φ(z) ≈ ½ + (h/3)[φ(0) + φ(z)
+ 4∑odd iφ(ih) + 2∑even i, 0<i<Nφ(ih)]

Trapezoid error is O(N⁻²); Simpson error is O(N⁻⁴) for fixed z. Both use N+1 density evaluations and O(1) memory. Simpson usually reaches a target accuracy with fewer intervals.

Series / evaluate erf directly

erf(t) = (2/√π) ∑k=0∞ (−1)kt2k+1/[k!(2k+1)]

The implementation updates each term recursively, avoiding powers and factorials. It stops when the next contribution is below a scaled 10⁻¹⁶ threshold, after the terms have begun decreasing, with a 200-term safety limit.

The series converges for all finite t in exact arithmetic, but cancellation can lose digits as |t| grows. Here |z| ≤ 5. Tail probabilities near zero are better computed using Φ(z) = ½ erfc(−z/√2), with an algorithm that evaluates erfc directly.

Why Liouville rules out an elementary formula

Liouville’s integration theorem constrains elementary antiderivatives to an algebraic term plus constant multiples of logarithms in a suitable differential field. A consequence is that ∫e−x²dx would be elementary only if a rational function R solved

R′(x) − 2xR(x) = 1.

A pole of R would give R′ a higher-order pole that −2xR cannot cancel. Thus R would have to be a polynomial. For a nonzero polynomial, −2xR has degree one higher than R and cannot be canceled by R′ to yield the constant 1. No such R exists.

A scaling of x gives the same obstruction for e−x²/2. This is the theorem about elementary integration, distinct from Liouville’s theorem in complex analysis.

Exact representation, numerical evaluation

Define erf(t) = (2/√π)∫0te−u²du. Substituting x = √2u into the normal integral gives the exact identity Φ(z) = ½[1 + erf(z/√2)].

Introducing a special function names the integral and supplies identities, derivatives and series. It does not turn the answer into elementary functions or produce decimal digits without computation.

For this experiment, Simpson is a short, accurate general method. For many repeated CDF evaluations, production libraries use carefully selected rational approximations, series and asymptotic formulas, with direct tail evaluation to control cancellation. A single power series is less robust across the whole real line.
